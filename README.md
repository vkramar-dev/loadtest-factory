# LoadTest Factory

**Load testing without complexity.**

LoadTest Factory is a lightweight, dependency-free load testing library for .NET, designed to make performance testing simple and accessible.

## Goals

- Simple and intuitive C# API.
- No external runtime dependencies.
- Single-assembly distribution.
- Concurrent execution of custom test scenarios.
- Real-time performance metrics.
- Detailed, self-contained HTML reports.
